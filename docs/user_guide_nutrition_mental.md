# AthleteIQ 营养与心理监测解读指南

## 面向教练与运动员 (基于 CPSS / 过度训练共识标准)

---

## 🍎 一、营养监测解读

### 1.1 为什么要监测营养

根据 CPSS (Certified Performance and Sport Scientist) 标准，**营养是运动恢复的四大支柱之一**（营养、睡眠、身体恢复、心理恢复）。运动员的营养状态直接影响：

- **训练适应**: 蛋白质不足 → 肌肉合成受阻，力量增长停滞
- **恢复速度**: 碳水补充不足 → 糖原耗尽，次日训练质量下降
- **免疫系统**: 能量摄入不足 → 上呼吸道感染风险增加 2-4 倍
- **过度训练**: 长期能量亏空是 OTS (过度训练综合征) 的核心诱因

AthleteIQ 通过每日营养日志持续追踪 5 个核心指标，建立运动员的**营养-表现关联模型**。

### 1.2 核心营养指标解读

#### 蛋白质充足度 (protein_sufficient: yes/no)

| 指标 | 说明 |
|------|------|
| **运动人群目标** | 1.6–2.0 g/kg/天 |
| **耐力运动员** | 1.2–1.6 g/kg/天 |
| **力量/爆发力运动员** | 1.6–2.2 g/kg/天 |
| **减重期运动员** | 2.0–2.4 g/kg/天 |

**判断**: 系统要求运动员评估今天是否摄入了足够的蛋白质（以正餐含优质蛋白为核心判断标准）。如果连续记录为"否"(no)，触发营养预警。

> **教练关注点**: 蛋白质摄入间歇性不足 OK，但连续 3+ 天不足 → 肌肉恢复受阻 → 训练效果打折。

---

#### 训练后补充 (post_training_refuel: yes/no)

| 窗口 | 建议 |
|------|------|
| **黄金窗口** | 训练后 30 分钟内 |
| **碳水:蛋白比** | 3:1 (例如: 60g 碳水 + 20g 蛋白) |
| **液体优先** | 巧克力奶、蛋白奶昔、运动饮料更方便快速吸收 |

**判断**: 次高强度以上训练（RPE ≥ 6）后是否在 30 分钟内补充。
连续缺省 → 糖原恢复不足 → 次日训练 RPE 偏高、能力下降。

> **教练提示**: 告诉运动员包里常备一根香蕉 + 一盒牛奶/豆浆，就是最简单有效的训练后补充。

---

#### 饮水量 (water_intake_liters)

| 状态 | 建议量 |
|------|--------|
| **日常最低** | 2.5 L/天（运动员） |
| **训练日** | 3.0–4.0 L/天 |
| **比赛日/高温** | 4.0+ L/天 |

**判断**:
- `< 1.5 L` → 脱水风险，认知能力下降，受伤风险升高
- `1.5–2.5 L` → 偏低，建议增加
- `> 2.5 L` → 正常
- `> 4.0 L` → 充分（比赛日可接受）

> **脱水识别**: 最简单的判断是**尿液颜色**——淡黄色 = 良好水合状态，深黄色 = 需要补水。

---

#### 食欲 (appetite_score: 1-5)

| 评分 | 含义 |
|------|------|
| **1** | 完全没有食欲 (严重) |
| **2** | 食欲差 |
| **3** | 正常 |
| **4** | 良好 |
| **5** | 非常好 |

**判断**:
- 评分 1-2 → 食欲下降
- **持续下降的食欲是过度训练的早期信号之一** (Meeusen et al. 2013)
- 食欲持续 < 3 超过 5 天 → 建议评估训练负荷、睡眠质量和心理状态

---

#### 晨起体重 (morning_weight_kg)

| 变化 | 含义 | 建议 |
|------|------|------|
| **± 0.5 kg** | 正常日常波动 | 无需关注 |
| **下降 1-2%** | 轻微脱水/能量亏空 | 增加饮水 + 碳水摄入 |
| **下降 > 2%** | 显著脱水/慢性能量不足 | 立即补水 + 评估训练负荷 |
| **连续下降** | 能量摄入不足风险 | 排查: 训练量是否突然增加? 是否有刻意减重? |

> **测量要求**: 每天早晨起床后排尿后、排便前，穿着相同（或裸体）称重。

---

### 1.3 营养风险算法说明

AthleteIQ 内置营养风险评估逻辑：

```
触发条件 (满足任一项):
1. 最近 7 天内，protein_sufficient = 'no' 的天数 ≥ 3
2. 最近 7 天内，water_intake_liters 日均值 < 1.5
3. 晨起体重连续 5 天下降且累计降幅 > 1.5%
4. 食欲持续 < 3 超过 5 天

风险等级:
- 满足 0 项 → 🟢 营养正常
- 满足 1 项 → 🟡 轻度风险
- 满足 2+ 项 → 🔴 高风险，自动生成营养预警
```

### 1.4 营养模板 (备赛期/比赛期) 解读

系统提供的备赛期 vs 比赛期营养模板差异：

| 方面 | 备赛期 | 比赛期 |
|------|--------|--------|
| **蛋白质** | 1.6–2.0 g/kg（维持合成） | 1.8–2.0 g/kg（比赛消耗大） |
| **碳水** | 5–7 g/kg（支持高强度训练） | 7–10 g/kg（糖原储备最大化） |
| **训练后补充** | 每次高强度训练后 | 每次训练/比赛后 |
| **饮水** | 3–4 L/天 | 3.5–4.5 L/天 |
| **赛前餐** | 不适用 | 赛前 3-4 小时，高碳水+中蛋白+低脂 |
| **赛中补给** | 不适用 | 每 60-90 分钟补充 30-60g 碳水 |

> **切换提醒**: 进入比赛期模板时，系统会自动提升碳水目标并增加赛前餐提醒。

## 🧠 二、心理监测解读

### 2.1 为什么要监测心理状态

根据 **CPSS 标准**和**欧洲运动科学学院过度训练共识 (Meeusen et al. 2013)**：

> **心理指标往往是最早出现的过度训练信号。** 在生理指标（HRV、晨脉）出现异常之前数周，运动员的情绪、动机、专注力就已经开始下降。

监测心理状态可以帮助：
- **提前预警**过度训练 (OTS) — 心理变化通常早于生理变化 2-4 周
- **评估恢复质量** — 充分恢复的运动员心理状态应稳定
- **发现外部压力** — 生活压力、学业、人际关系影响训练表现
- **个性化教练沟通** — 了解运动员心理状态后调整沟通方式和训练安排

### 2.2 核心心理指标解读

所有评分采用 1-5 自评量表（1 = 很低/很差，5 = 很高/很好）。

#### 情绪 (mood_score: 1-5)

| 评分 | 状态 | 行动 |
|------|------|------|
| **4-5** | 积极、稳定 | 正常推进训练 |
| **3** | 中性 | 可接受，但关注趋势 |
| **1-2** | 消极、低落 | 需要教练沟通 |

**判断**:
- **持续 < 3 超过 5 天** → 可能提示抑郁情绪或 OTS (过度训练综合征)
- **单日波动** → 正常（可能受睡眠、生活事件影响）
- **趋势性下降** → 重点关注的预警信号

---

#### 专注力 (focus_score: 1-5)

| 评分 | 状态 | 含义 |
|------|------|------|
| **4-5** | 高度专注 | 神经系统状态良好 |
| **3** | 中等 | 可维持训练质量 |
| **1-2** | 难以集中 | CNS (中枢神经系统) 疲劳标志 |

**判断**: **专注力下降是中枢神经系统 (CNS) 疲劳的核心标志**。如果运动员报告"训练时注意力涣散"、"反应变慢"，优先考虑：
1. 睡眠不足
2. 连续高强度训练导致 CNS 疲劳
3. 碳水摄入不足（大脑燃料不足）

---

#### 训练动机 (motivation_score: 1-5)

| 评分 | 状态 | 含义 |
|------|------|------|
| **4-5** | 渴望训练 | 正常竞技状态 |
| **3** | 动机中等 | 可接受 |
| **1-2** | 缺乏动力 | 需关注 |

**判断**: **低动机 + 高疲劳 = 经典 OTS 模式** (Meeusen et al. 2013)。如果运动员报告：
- 动机 < 3 且 疲劳 > 4 → 立即评估训练负荷
- 动机 < 3 持续 7+ 天 → 检查是否存在心理倦怠 (burnout)
- 动机 < 3 但疲劳分数正常 → 可能来自外部压力（生活/学业），非训练原因

---

#### 心理疲劳 (mental_fatigue_score: 1-5)

| 评分 | 状态 |
|------|------|
| **1-2** | 精力充沛 |
| **3** | 中度疲劳 |
| **4-5** | 高度心理疲劳 |

**判断**: 心理疲劳是一个**累积性指标**：

- 单日高分 → 可能由前一天的高强度训练或睡眠不佳导致
- 连续 3+ 天高分 → CNS 恢复不足
- 心理疲劳高 + 食欲下降 + 情绪低落 → 这是 OTS 三联征，必须立即干预

---

### 2.3 心理周报解读

AthleteIQ 每周自动生成心理状态周报，核心判断标准：

```
📊 心理状态周报判断逻辑:

1. 单项指标趋势分析:
   - 任一指标周均值 < 2.5 → ⚠️ 该维度亮黄灯
   - 本周均值较上周下降 > 20% → ⚠️ 该维度亮红灯

2. 综合心理指数:
   - 四项指标(情绪+专注+动机+心理疲劳反向) 加权平均
   - 指数 > 3.5 → 🟢 心理状态良好
   - 指数 2.5–3.5 → 🟡 关注
   - 指数 < 2.5 → 🔴 建议干预

3. 触发行动的条件:
   - 连续 2 周心理指数下降 > 20%
   - 单项指标 < 2.5 持续 7 天
   - 三项及以上指标同时下滑
```

**报告内容包含**:
- 各指标周均值与上周对比（% 变化）
- 趋势图（4周滚动）
- 自动生成建议（如: 建议安排 1-2 天主动恢复 / 建议教练与运动员沟通 / 建议评估睡眠质量）
- 历史同期对比（去年同期数据，如有）

### 2.4 RESTQ-Sport 简化版 使用指南

**RESTQ-Sport (Recovery-Stress Questionnaire for Athletes)** 是运动心理学领域最权威的恢复-应激评估工具。AthleteIQ 集成了简化版（19项），涵盖:

| 维度 | 条目数 | 测量内容 |
|------|--------|----------|
| **一般应激** | 4 | 生活压力、焦虑、情绪困扰 |
| **运动专项应激** | 4 | 训练负荷感知、比赛压力、伤病恐惧 |
| **一般恢复** | 4 | 睡眠质量、社交恢复、放松能力 |
| **运动专项恢复** | 4 | 身体恢复感、技术信心、训练投入度 |
| **总体评价** | 3 | 整体状态自评 |

#### 使用时机

| 训练阶段 | 建议频率 |
|----------|----------|
| **大负荷训练板块** (备赛期高强度周) | **每周 1 次** |
| **常规训练期** | **每 2 周 1 次** |
| **比赛期** | 赛前 3 天和赛后 1 天各 1 次 |
| **过渡期** | 开始和结束各 1 次 |
| **伤病恢复期** | 每 2 周 1 次 |

#### 评分与解读

每个条目 0-6 分（0 = 从不，6 = 总是）：

```
📊 RESTQ-Sport 简化版解读

恢复-应激差值 = 恢复维度总分 - 应激维度总分

差值解读:
  > +10    🟢 恢复状态良好，训练适应正常
  0 ~ +10  🟡 恢复略占优，可维持当前负荷
  -10 ~ 0  🟠 应激超过恢复，建议减少 20-30% 容量
  < -10    🔴 严重应激，建议暂停高强度训练 3-7 天

关键趋势:
  - 连续 2 次评估差值下降 > 5 分 → 触发预警
  - 差值转负且持续下降 → 过度训练高风险
```

> **操作提示**: 在运动员详情页 → 「心理监测」标签 → 点击「RESTQ-Sport 评估」→ 填写后自动生成报告。建议教练在评估后 24 小时内查看并与运动员沟通。

### 2.5 心理预警与教练应对策略

| 预警类型 | 触发条件 | 教练应对 |
|----------|----------|----------|
| **轻度心理疲劳** | 心理疲劳 > 3 连续 3 天 | 增加 1 天恢复日，询问睡眠质量 |
| **中度情绪下滑** | 情绪 < 3 连续 5 天 | 1对1沟通，了解生活/学业压力 |
| **动机丧失** | 动机 < 3 + 疲劳 > 4 连续 3 天 | 暂停高强度训练，安排多样化活动 |
| **CNS 疲劳** | 专注力 < 3 + 心理疲劳 > 4 连续 5 天 | 降低训练容量 40-50%，增加恢复天数 |
| **OTS 风险** | 三项指标同时恶化 + RSSI > 50 | 联系运动医学专业人员，全面评估 |

> **关键原则**: 心理预警出现后，**不要简单归因于"意志力不足"**。绝大多数情况是训练负荷、恢复质量、营养状态等可干预因素导致的。先调整训练，再评估心理变化。
