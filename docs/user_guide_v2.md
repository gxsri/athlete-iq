# AthleteIQ v2.0 新功能使用指南

## 六、运动员管理模块

### 6.1 运动员列表
进入侧边栏「运动员管理」，可以看到所有运动员的卡片列表。
- 顶部搜索框可按姓名、项目搜索
- 可按运动项目、队伍分组、状态（正常/康复/预警）筛选
- 每张卡片显示：姓名、项目、最新 ACWR（绿/黄/红标注）、RSSI 状态、活跃预警数
- 点击「添加运动员」弹出注册表单
- 点击「批量导入」可上传 CSV 文件

### 6.2 运动员详情（三个标签页）
点击任意运动员卡片进入详情页：

**档案标签**
- 基本信息：姓名、性别、出生日期、运动项目、训练年限、位置
- 个人基准测试数据（深蹲/卧推/硬拉1RM、CMJ纵跳、30m冲刺、VO₂max）
- 体能雷达图：显示当前值、历史最佳、项目常模区间（自动高亮落后素质）

**伤病与恢复标签**
- 伤病记录列表：诊断、日期、预计恢复周数、当前状态
- 每日康复日志：疼痛评分(0-10)、康复完成度
- 「回归赛场」检查清单：教练设定的必须达标指标及阈值
- 训练计划会自动识别活跃伤病限制

**历史数据标签**
- 训练负荷趋势图
- 身体测试结果趋势
- 准备状态问卷趋势

## 七、训练日志模块

### 7.1 每日准备状态问卷（运动员必填）
运动员每日首次打开训练日志时，会看到卡片式问卷：
- 睡眠质量 (1-5)
- 肌肉酸痛 (1-5)
- 整体疲劳感 (1-5)
- 心理压力与训练动机 (1-5)
- 不适部位描述（可选）

提交后页面顶部显示绿色/黄色/红色状态圆点，数据自动纳入 RSSI 计算。

### 7.2 填写训练日志
- 选择日期、训练类型、RPE (1-10)
- 输入训练时长（自动计算 Session RPE Load）
- 点击「添加动作」从动作库选择动作（深蹲、卧推、药球抛砸等）
- 填写重量、次数、组数、RPE、备注
- **计划对比**：如果当日有教练安排的计划，动作列表会预填计划参数；运动员只需修改实际完成数据；保存时自动计算偏差率

### 7.3 教练批注与评分
教练可在日志详情页：
- 输入文字批注
- 给出 1-10 分技术执行评分
- 批注保存后运动员可见

## 八、训练安排模块（教练专用）

### 8.1 快捷动作添加
侧边栏展示完整的动作库，按类别分组：
- 基础力量（深蹲、卧推、硬拉等）
- 爆发力（高翻、药球抛砸等）
- 速度（冲刺、敏捷梯等）
- 代谢（间歇跑、划船机等）
- 恢复（泡沫轴、拉伸等）
- 核心（平板支撑等）

点击任意动作卡片直接加入训练课，弹出参数设置窗口（重量、次数、组数、间歇、RPE目标）。

### 8.2 训练课编排
- 动作顺序可调整（上下箭头）
- 可删除动作
- 填写训练课名称和备注
- 保存后可分配给单个运动员或多位运动员
- 分配后运动员在指定日期即可看到训练计划

### 8.3 周期化模板库
NSCA 标准周期模型：
- 线性周期：每周递增强度、递减容量（4周）
- 非线性/DUP：每日变化（周一力量耐力/周三基础力量/周五爆发力）
- 板块周期：2周集中负荷 + 恢复
- 过渡期：低强度交叉训练

教练可在训练安排页面点击「从模板创建」，选择模板后自动填充每日训练内容，也可修改后保存为自定义模板。

## 九、预警中心增强

### 9.1 智能减载周提醒
当系统检测到：
- ACWR > 1.3 连续 ≥ 14天
- HRV 出现下降趋势或准备状态问卷恶化

自动生成「减载周建议」通知，附带自动生成的减载模板（强度不变、容量降低40%、增加恢复日）。教练可在通知中一键跳转到训练安排页面采纳。

### 9.2 执行偏差预警
当运动员连续3天实际训练量偏离计划超过±20%时，系统自动触发预警。

## 十、报告中心

- 选择运动员和时间范围
- 一键生成月/半月报告
- 包含：ACWR 趋势图、RSSI 变化、体能对比、教练批注摘要、训练建议
- 标注报告符合 NSCA-CSCS/CPSS 标准

## 十一、团队热力图（教练端仪表板）

在教练仪表板新增「团队总览」视图：
- 表格/热力图呈现所有运动员
- 列：姓名、ACWR（颜色标注）、RSSI、最近负荷、体能趋势箭头、伤病数
- 顶部显示：团队平均 ACWR、高风险运动员占比
- 可按队伍分组聚合
- 点击行可钻取到运动员详情
